# 📊 ReviewPulse Analytics - Customer Review Insights Engine

An interactive Streamlit web application designed for real-time sentiment analysis, visual diagnostics, and automated insight generation from customer reviews using Natural Language Processing (NLP).

---

## 🚀 Features
- **Real-Time Sentiment Classification:** Classifies customer reviews into **Positive**, **Negative**, or **Neutral** sentiments using TextBlob.
- **Interactive Visual Breakdown:** Displays percentage distribution of customer feedback using dynamic Plotly charts.
- **Word Cloud Diagnostics:** Highlights key words and descriptors frequently used in customer feedback.
- **Filtered Data Export:** Allows filtering data by specific sentiment and exporting processed CSV files.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **NLP & Data Processing:** TextBlob, Pandas, NumPy
- **Data Visualization:** Plotly, WordCloud, Matplotlib
